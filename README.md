## Projects

### 🔮 [Customer Churn Prediction — Live Streamlit App](https://github.com/rohit890271/Customer-churn-prediction)
*(2025 · Python, Scikit-learn, Pandas, Streamlit)*

I cleaned a Telco customer dataset, tuned a Random Forest classifier using GridSearchCV, and deployed the whole thing as a live Streamlit app. It hits a ROC-AUC of **0.84**.

What I care about here isn't just the model score — it's that I can walk through the entire pipeline, from raw data to a working UI that someone non-technical can actually use. I built this because I wanted to understand ML end-to-end, not just the modelling part.

---

### 🛒 [E-Commerce Analysis with BigQuery](https://github.com/rohit890271/thelook-ecommerce-analysis)
*(2026 · SQL, BigQuery · TheLook public dataset)*

Analysed customer behaviour and product performance across a dataset with 500K+ sessions. The work involved window functions, customer segmentation, retention analysis, revenue reporting, and anomaly detection to flag unusual traffic patterns.

Honestly this one sharpened my SQL more than anything else. BigQuery at that scale forces you to think about query efficiency in a way that smaller datasets don't.

I built this to get proper hands-on time with a BI tool and understand what makes a dashboard useful versus just visually busy.
